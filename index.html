SLIDE 02 · MERANCANG LOGIKA

Kalkulator Flowgorithm.

IF / ELSE

Percabangan menentukan perhitungan berdasarkan operator yang dipilih.

Input dua angka & operator↓Periksa kondisi if / else↓Hitung → tampilkan hasil

Jika operator +, jumlahkan. Jika tidak, periksa −, lalu ×. Setiap kondisi mengarahkan program ke proses yang sesuai.

Contoh: 12 + 4 → kondisi “+” benar → hasil 16.

SLIDE 03 · MENULIS & MENJALANKAN KODE

Praktik Google Colab.

PYTHON

Mengubah alur kalkulator menjadi kode Python di dalam notebook.

  • input() menerima angka dan operator.
  • float() mengubah input menjadi angka.
  • if / else memilih operasi hitung.
  • print() menampilkan hasil program.
CONTOH LOGIKA PYTHON
if operator == "+":
    hasil = angka1 + angka2
else:
    hasil = angka1 - angka2
print(hasil)

Contoh sederhana untuk operasi + dan −. Untuk pembagian, gunakan angka kedua sebagai pembagi dan periksa agar tidak nol.
